Quick pick guide

  • Want the spec in docs/issues/browse-recipes.md? Use Option A (2×2 grid + square + cover).
  • Still too tall on phone? Try B (4:5) or C (3:2).
  • Want max recipes above the fold? D drops the caption row.
  • Letterboxing usually means object-fit is not cover or the image is not given height: 100% inside the aspect-ratio box — fix that even if you keep 1 column.
  • Desktop: Option A keeps today’s auto-fill grid; only add a @media (max-width: 768px) rule for 2 columns. Options B/C/D change tile height on all screen sizes.
